> **Procedural generation of a symmetric 6-pointed star in ASCII art**, calculated strictly according to scale parameter $N$.

---

## ⚙️ Mathematical Properties

Given size $N$:
- Top and bottom vertex heights: $N$ lines.
- Central horizontal bar length: $6N + 1$ characters.
- Slope angles: Exact linear spacing offsets using spaces and `'*'`.
